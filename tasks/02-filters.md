# Поиск и фильтрация

Добавить поиск по заголовку и пересказу без учёта регистра, выбор тега и флажок «Только непрочитанные». Список вычислять при отрисовке.

## Готово, когда

Поиск находит слово в пересказе. Тег сочетается с поиском и флажком. При пустой выборке видно «Новостей не найдено». У всех полей есть видимые подписи.
