# Отметки о прочтении

Переключать состояние новости по кнопке. Хранить только идентификаторы прочитанных записей в localStorage под ключом digest-read.

## Готово, когда

Кнопка работает с клавиатуры. При повторном открытии страницы прочитанная запись сохраняет отметку. Повторное нажатие снимает отметку. Под фильтром непрочитанных отмеченная карточка исчезает.
