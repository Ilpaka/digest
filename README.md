# Дайджест новостей

Учебный проект модуля 4 по дисциплине «Angular и React». На странице можно найти новость по заголовку или пересказу, выбрать тег и оставить только непрочитанные материалы. Кнопка под карточкой сохраняет отметку в этом браузере. Даты показаны по московскому времени.

[Дайджест на GitHub Pages](https://ilpaka.github.io/digest/) · [Задания агенту](tasks/) · [Журнал решений](ai-log.md)

## Запуск

Для работы нужен Node.js 24 актуальной версии.

```sh
npm ci
cp .env.example .env
npm run dev
```

С пустым `VITE_DIGEST_URL` открывается сохранённый выпуск из трёх RSS-лент. Чтобы получать изменения из таблицы при каждом открытии страницы, укажите в этой переменной публичный адрес Apps Script с окончанием `/exec`. Для GitHub Pages задайте тот же адрес в настройках репозитория в **Settings → Secrets and variables → Actions → Variables**, затем запустите публикацию заново. Переменная используется во время сборки.

```sh
npm run lint
npm test
npm run build
```

Проверки запускаются в том же порядке при отправке в main. Тесты подменяют сеть. Они проверяют загрузку, ошибку HTTP, порядок карточек, поиск, совместную работу фильтров и восстановление отметок о прочтении.

## Утренняя и вечерняя автоматизация

Утром в 08:00 МСК n8n читает RSS Хабра, Naked Science и iXBT, берёт до пяти материалов за последние сутки из каждого источника и передаёт их модели Qwen3. Модель готовит пересказы и теги. Apps Script сохраняет новые записи по идентификатору. В 19:00 МСК вечерний процесс читает таблицу и формирует одно сообщение со ссылками для Telegram.

1. В учебной Google Таблице создайте лист `news` и внесите в первую строку семь заголовков в таком порядке — `id`, `date`, `source`, `title`, `summary`, `tags`, `link`.
2. Через **Расширения → Apps Script** вставьте [Code.gs](automation/apps-script/Code.gs). В свойствах скрипта добавьте `KEY` со случайным ключом записи. Разверните веб-приложение от своего имени с доступом для всех. Откройте адрес `/exec` в приватном окне браузера. Для нового листа ожидается ответ `{"news":[]}`.
3. В локальном `React/avtomatizaciya/.env` учебного репозитория задайте `DIGEST_URL` (адрес `/exec`), `DIGEST_KEY` (значение `KEY`), `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Значения, дающие право записи или отправки сообщений, нужны только серверу. [Конфигурация Docker Compose](https://github.com/Ilpaka/TDSDB/tree/main/React/avtomatizaciya).
4. Из этой папки выполните `docker compose up -d n8n ollama` и `docker compose exec ollama ollama pull qwen3:4b-instruct`. Откройте n8n по адресу `http://localhost:5678`.
5. Импортируйте [утренний процесс](automation/n8n/collect.json) и [вечерний процесс](automation/n8n/evening.json). Запустите их вручную по очереди. Проверьте новые строки в листе и сообщение в личном чате бота. Повторный утренний запуск с теми же новостями должен добавить ноль строк. Для работы по расписанию опубликуйте оба процесса в n8n и оставьте Docker запущенным.

За основу взяты процессы и скрипт преподавателя. Лента 3DNews при проверке вернула HTTP 403, поэтому третьим источником выбрана русскоязычная научная лента.
