# Правила проекта

Дайджест новостей работает на React 19, TypeScript и Vite 8. Версии зависимостей зафиксированы в package-lock.json. Для разработки и CI используется Node.js 24.

## Данные

Публичный адрес Google Apps Script передаётся как `VITE_DIGEST_URL`. Ответ на GET — объект с массивом `news`. Каждая запись содержит строковые поля `id`, `date` (ISO 8601), `source`, `title`, `summary`, `tags` и `link`. Теги передаются одной строкой, например «ИИ, наука». Запись в таблицу выполняет n8n. Ключ записи и данные Telegram хранятся вне репозитория.

## Проверка изменений

Выполняйте задания из каталога tasks. Сначала сформулируйте проверяемый результат, затем измените код и проверьте его командами `npm run lint`, `npm test`, `npm run build`. Для тестов интерфейса подменяйте сеть. В журнале ai-log.md различайте проверку агента и личную приёмку автором работы.
